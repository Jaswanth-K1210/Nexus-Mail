# Security Policy

## Reporting a vulnerability

Email **security@nexus-mail.me** with a description, steps to reproduce and the impact.
Please do not open a public GitHub issue for security problems.

We will acknowledge your report within 3 business days, keep you updated, and
credit you in the fix (unless you prefer otherwise) once it is released.

## Scope

- The hosted service at `nexus-mail.me` and its API
- The code in this repository

Out of scope: denial-of-service, social engineering, spam, findings that need a
compromised device, and reports from automated scanners without a working proof.

## Safe harbour

Good-faith research that follows this policy, avoids privacy violations and
service disruption, and only uses accounts you own will not be pursued legally.
Never access, modify or keep other users' data. Stop and report as soon as you
reach any.

## Supported versions

Only the latest `main` branch, which is what runs in production, receives fixes.
